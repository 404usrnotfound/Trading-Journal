Full archives have a different scope. Changing the export population to analytics hides ordinary filters but can retain their values; clear incompatible values before switching.
- **Historical prose:** existing phase references, including parts of [imports](../imports.md), describe earlier deferred functionality. Current task chapters explain the delivered UI and point to source. Historical audit narratives were preserved rather than silently rewritten; the [documentation plan](../documentation-plan.md) tracks verification/ownership.
- **Undelivered scope:** live broker/feed connectivity, automatic placement, universal advanced-asset lifecycle/tax engines, AI review, MAE/MFE/slippage and optional risk-adjusted modules have no delivered user workflow. Entity-wide custom fields and varied seeded demo history remain partial. Production capacity [FA-04](../final-audit.md) remains open; this checkpoint changes no release gate.
