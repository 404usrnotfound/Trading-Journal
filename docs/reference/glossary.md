## Workspace and reference records

| Term                     | Meaning in Trading Journal                                                                                                                                                                            |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Workspace                | The shared scope for accounts, financial records, strategies and reviews. Membership determines who may read or edit it. Confirm it before recording activity.                                        |
| Broker                   | The institution or source associated with an account. Creating a broker record does not connect to a live broker or place orders.                                                                     |
| Account                  | The custody and accounting scope that owns actual cash and holdings. Its base currency does not prevent it from holding other currencies.                                                             |
| Paper account            | An account labeled for simulated activity. Reports keep paper and live populations separate; recording here does not execute a real market trade.                                                     |
| Cash bucket              | A currency-specific part of an account, such as settled, unsettled, restricted or collateral cash. Creating a bucket does not put money into it.                                                      |
| Currency / monetary unit | The unit of a money amount. A code such as USD is a label; the stored currency identity and conventions determine which amounts can be combined.                                                      |
| Instrument               | A particular economic asset or contract. A symbol alone does not establish identity or supported accounting.                                                                                          |
| Instrument version       | The immutable economic conventions used for a fill, such as units, quote and settlement currency, multiplier and settlement style. Later metadata does not silently rewrite old fills.                |
| Portfolio                | A named, versioned selection of accounts in one environment. Reports use an exact membership version. Two portfolios can overlap, so their totals may count the same account twice if added together. |

## Orders, fills and trading ideas

| Term                            | Meaning in Trading Journal                                                                                                                                                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Order                           | A recorded instruction to buy or sell. An unfilled order creates no holding or principal cash movement. An order canceled after a partial fill still has that actual fill.                                                            |
| Execution / fill                | An actual recorded purchase or sale with quantity, price, economic time and source evidence. One order may have several fills. A fill alone is not a completed campaign.                                                              |
| Trade / campaign / trading idea | The decision and review unit shown in the Journal. It can contain multiple entries, exits, legs and accounts. All three terms refer to the campaign, not to a single fill.                                                            |
| Campaign leg                    | The account, instrument and intended direction of one part of a campaign. Scaling into or out of the same leg adds actual allocations to that leg.                                                                                    |
| Allocation / attribution        | The assignment of a fill's quantity, principal and costs to campaign legs, with an explicit unassigned remainder where needed. This assigns analytical ownership; it does not book another fill or move cash again.                   |
| Position / holding book         | Rebuilt actual inventory for a compatible account and instrument scope. A campaign's analytical exposure is a separate view of conserved allocations.                                                                                 |
| Lot                             | An opening slice of inventory with its quantity, principal basis, costs and acquisition lineage. Partial exits consume part of a lot and retain the rest.                                                                             |
| FIFO                            | First in, first out: eligible earlier lots are consumed first. Campaign attribution uses its own FIFO sequence, which can differ from the account's selected inventory policy.                                                        |
| Average cost / specific lot     | Alternative supported account matching policies: consume compatible pooled contributions proportionally, or explicitly select eligible source lots. They are analytical policies and do not certify tax treatment.                    |
| Long / short                    | Long inventory benefits from a price increase; short inventory has negative signed holding value. Native short support has additional convention requirements; a sell that closes a long holding is not automatically a new short.    |
| Scale in / scale out            | Add to an existing idea / close only part of it. Choose the existing campaign and matching leg explicitly when recording each fill.                                                                                                   |
| Flat / completed                | Flat means no remaining exposure. Completed additionally requires accepted campaign closure and supported order/settlement obligations to be satisfied. A flat campaign awaiting closure stays outside completed-campaign statistics. |
| Strategy / strategy version     | A playbook and the immutable published rules linked to a campaign. Updating a strategy does not change the historical version used by an existing campaign. Narrative rules are distinct from evaluated risk policies.                |
| Plan / original committed risk  | A recorded intention / the positive risk amount in the original plan genuinely committed before the earliest effective fill. A later plan or risk addition cannot become the original denominator for historical R.                   |
| Journal / period review         | The campaign's plans, notes and reviews / a separate saved assessment of a selected reporting period. Commentary does not overwrite ledger actuals.                                                                                   |

See [recording](../advanced-financial-entry.md), [journals](../trade-journal.md) and [strategies](../strategies.md) for the workflows.

## Cash, currency and source evidence

| Term                                 | Meaning in Trading Journal                                                                                                                                                                                                                        |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cash movement / cash event / posting | An actual classified monetary effect / its ledger event / one signed entry in that event. Events balance within each currency; cash balances count the cash postings, not ledger controls.                                                        |
| Transaction                          | An informal source term. Determine whether the source means an order, execution, fee, conversion or cash movement before recording it. Those are distinct records in this application.                                                            |
| Principal                            | The actual gross amount exchanged for an execution or conversion, before separately recorded fees. Price multiplied by quantity and actual booked principal can differ under a verified booking convention.                                       |
| Deposit / withdrawal                 | Capital entering / leaving the selected account scope. These change cash and equity but are excluded from investment performance.                                                                                                                 |
| Opening balance / opening lot        | Explicit starting cash or holdings at a reviewed boundary. An opening record does not invent earlier profit, acquisition price or fees.                                                                                                           |
| Internal transfer                    | Movement between owned accounts or cash buckets. Transfers within a selected consolidated scope cancel; crossing its account boundary is a capital movement for that report.                                                                      |
| Money in transit                     | An evidenced owned claim between a transfer's actual departure and receipt. It is counted once in the scope containing both endpoints, then replaced by received cash. An expected arrival is not an actual receipt.                              |
| Actual FX conversion                 | An exchange that debits one currency and credits another, using actual source and destination amounts and separately recorded fees.                                                                                                               |
| Reporting translation                | Expressing an amount in a selected reporting currency using eligible reference FX. It changes the report, without exchanging cash.                                                                                                                |
| Observation / mark                   | A dated source fact such as a price, FX rate or broker account value. A mark values a holding; it does not establish its missing acquisition basis or move money.                                                                                 |
| Supplied analysis component          | An explicitly reviewed, compatible source value selected for a supported analytical role. It does not post cash or enable automatic pricing for an unsupported instrument.                                                                        |
| Economic time / recorded time        | When the source event actually occurred / when the application accepted its record. A later recorded correction may restate an earlier economic event in a new source revision.                                                                   |
| Source revision / provenance         | The financial history boundary used by a calculation / the references explaining the source facts, observations, versions and policies it used. Keep them when comparing reports.                                                                 |
| Reversal / refund                    | An appended negation correcting an erroneous source / an actual later money return at its own date. They have different historical effects.                                                                                                       |
| Reconciliation                       | Comparing expected and calculated components, or comparing against an independent statement. A zero internal reconciliation variance establishes arithmetic agreement within its inputs; an independent statement comparison is a separate check. |

See [account accounting](../portfolio-accounting.md), [corrections](../account-performance-and-corrections.md), [supplied values](../supplied-values.md) and [statement reconciliation](../statement-reconciliation.md).

## Results and their availability

| Term                                         | Meaning in Trading Journal                                                                                                                                                                                                                                                                                                                                                         |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Native currency / reporting currency         | The original monetary unit of a result / the selected common unit used for a translated report. Unlike native currencies cannot be added directly.                                                                                                                                                                                                                                 |
| Gross basis / net basis / Journal Cost basis | Gross basis is retained booked principal. Net basis adds remaining assigned entry and carrying charges under the declared convention; the Journal's **Cost basis** displays that net basis. After the example's partial sale, USD `420` principal plus USD `1.5` retained charges gives displayed cost basis `421.5`. This economic basis is not a jurisdictional tax calculation. |
| Average entry price                          | The weighted compatible original quoted prices of remaining lots, from fills or reviewed opening-lot inputs, excluding fees. It is distinct from net basis divided by quantity. Missing original quoted prices or a closed position make it unavailable.                                                                                                                           |
| Realized P&L                                 | Profit or loss from inventory matched to an actual exit. A partial exit realizes only the matched portion. A known realized amount does not prove the whole campaign is complete.                                                                                                                                                                                                  |
| Unrealized P&L                               | Profit or loss on remaining holdings valued at an eligible mark. It needs compatible basis and source coverage; it is not sale proceeds or a promise of the eventual exit result.                                                                                                                                                                                                  |
| Gross / net P&L                              | Before actual attributed charges / after those charges once. Preserve the declared population, currency and cost completeness when comparing results.                                                                                                                                                                                                                              |
| Fee / rebate                                 | A positive actual expense / a negative expense. Fees already reduce cash. Their analytical lot and campaign allocations are views of the original charge, not additional debits.                                                                                                                                                                                                   |
| Account equity / NAV / net liquidation value | In the implemented account report, translated owned cash, signed supported holdings and evidenced owned transit. Equity and net liquidation value use the same definition here; hypothetical future liquidation fees are not estimated.                                                                                                                                            |
| Account performance                          | The monetary change in equity after removing net capital flows for the selected period. Campaign P&L uses a different population and can omit account conversion costs, income or other account activity.                                                                                                                                                                          |
| Raw NAV / flow-adjusted series               | Actual valued equity at each checkpoint / a unit index that removes the effect of capital flows under the account return contract. A deposit may raise raw NAV without generating a return.                                                                                                                                                                                        |
| TWR / MWR                                    | Time-weighted period return, chaining supported flow-separated growth / money-weighted annualized return using dated investor cash flows under ACT/365. Both have evidence and mathematical sufficiency gates.                                                                                                                                                                     |
| R multiple                                   | A complete campaign's net outcome in its original risk currency divided by its eligible original committed risk. R is a risk multiple, not a percentage return; missing original risk leaves it unavailable.                                                                                                                                                                       |
| Expectancy                                   | The average net monetary result per eligible completed campaign in the selected sample. Expectancy in R uses only the independently eligible original-risk sample. Neither predicts a future outcome.                                                                                                                                                                              |
| Profit factor                                | Total positive completed net outcomes relative to the magnitude of total negative outcomes. All winners give an explicit infinite state; all breakevens give an undefined/unavailable result.                                                                                                                                                                                      |
| Drawdown / recovery                          | Decline below a prior peak / the observed return to that peak. Campaign drawdown uses cumulative closed net P&L in money. Account drawdown uses the sampled flow-adjusted unit index; the two measures are different.                                                                                                                                                              |
| Available / zero                             | Required compatible inputs support the result / those inputs establish an actual zero. Zero is a value, not a substitute for missing information.                                                                                                                                                                                                                                  |
| Partial / unavailable / unsupported          | Some named components are known but the total is incomplete / the result lacks required inputs or is undefined / the automatic operation has no validated native support. Preserve explanations and known subtotal labels.                                                                                                                                                         |

The precise result units, formulas, samples and availability codes are owned by [financial metrics](../financial-metrics.md), [analytics definitions](../analytics-definitions.md) and [account return definitions](../account-performance-and-corrections.md#account-series-and-return-definitions).
