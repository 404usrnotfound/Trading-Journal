# Reviewed supplied values

Use **Supplied values** for source-valued analysis of instruments whose automatic accounting is unavailable. The source form retains a position residual or a campaign net result with its original decimal value, currency, observation instant, source/reference, quality and financial revision. It does not post cash, create fills or enable an unvalidated instrument formula.

A position component requires a manual instrument convention effective at the observation instant and the exact signed source holding quantity. Choose an existing convention or enter a historical version ID. Declare delivered market value or residual contract equity and the accrual treatment. Confirm that the value excludes ledger cash, collateral balances, already settled P&L and existing unsettled cash claims. Those exclusions prevent counting the same source economics twice.

For example, an account with100 cash receives5 actual settled variation margin. Its cash is105. A separately evidenced remaining contract value of7 produces equity 112 when explicitly selected. It does not produce117 by adding the settled5 again, and it does not deduct the original futures quote or theoretical notional from cash.

A campaign component retains either completed realized net or lifetime total net, with all relevant source costs included. It requires a campaign containing a manual instrument leg. It replaces the compatible campaign result rather than adding another result or cash event. Campaign lifecycle and original-risk sufficiency still control completed-outcome/R eligibility; a supplied result does not itself close the campaign or invent historical risk.

Review the full source and definition before confirmation. Missing required attestations block review. A lost confirmation freezes the exact request for safe idempotent retry. Corrections append a source with `supersedesId`; the original remains immutable and can still be selected at a compatible earlier financial revision. A second competing replacement conflicts.

Reports use these values only after explicit selection. Accounts offers **Price and FX evidence policy → Reviewed supplied position values**. Dashboard offers reviewed campaign-result selection. Selections are retained in report URLs. The source history also links to the appropriate report. API callers use `suppliedPositionIds` for accounting/financial valuation or `suppliedCampaignResultIds` for analytics/dashboard requests.

Every selection checks tenant and calculation kind, source revision, corrections, observation boundary and freshness. Position quantity must still match at that boundary. The source basis is conservatively invalidated by later workspace financial changes; new prices/FX/account-value observations, other supplied observations and a projection refresh do not themselves change the reviewed economics. Reconfirm a new source after a relevant source-state rejection rather than ignoring the stale warning.

Reporting translation uses explicit compatible FX evidence and decimal rounding. Missing FX and numeric overflow remain explained unavailable results. An evidenced zero requires no invented exchange rate. A supplied component may establish closing equity while opening value, automatic trading/FX decomposition or period performance remains unavailable. Report dependencies retain the selected source and definition so a source-valued result can be distinguished from native calculation.

Focused regression coverage includes exact cash 105 plus residual 7, independent source/time/quantity/tenant validation, source correction history, explicit selection and populated archive restore. Additional independent cases cover cross-currency residuals,36-place values with18-place FX, adjacent microseconds, missing FX, overflow and zero translation. Source UI tests cover review, exclusions, historical metadata, paging, viewers and lost-response retries. Final complete and browser results are recorded in [the final audit](final-audit.md).
